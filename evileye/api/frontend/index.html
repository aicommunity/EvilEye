Видеопотоки

Для каждого работающего пайплайна: кадр (Snapshot), статус потока (Stream Status), видеопоток (MJPEG). Остановить пайплайн можно на вкладке «Пайплайны».

Конфигурации

Файлы конфигурации в формате JSON. Можно просматривать, создавать, редактировать и удалять.

    Новый пайплайн

    Создайте пайплайн по выбранному конфигу или вставьте свой JSON. После запуска видеопоток появится на вкладке «Видеопотоки».

    Список пайплайнов

    Создайте пайплайн, запустите его — видеопоток будет доступен на вкладке «Видеопотоки». Здесь: запуск, остановка, удаление, детали.
