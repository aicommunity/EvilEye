# ROI Editor Source Integration Summary

## Обзор изменений

ROI Editor теперь интегрирован с системой активных источников, аналогично Zone Window, что позволяет получать изображения напрямую из выбранных источников.

## Ключевые изменения

### 1. VideoThread обновления
- ✅ Добавлен сигнал `add_roi_signal = pyqtSignal(int, QPixmap)`
- ✅ Добавлена переменная `is_add_roi_clicked` для отслеживания состояния
- ✅ Добавлен метод `add_roi_clicked(thread_id)` для активации режима ROI
- ✅ Обновлена логика в `process_image()` для отправки изображений в ROI редактор

### 2. MainWindow обновления
- ✅ Добавлен сигнал `add_roi_signal = pyqtSignal(int)`
- ✅ Добавлен слот `open_roi_win(label_id, pixmap)` для получения изображений
- ✅ Обновлен метод `open_roi_editor_window()` для работы с активными источниками
- ✅ Добавлен метод `emit_add_roi_signal()` для обработки кликов по источникам

### 3. DoubleClickLabel обновления
- ✅ Добавлен сигнал `add_roi_signal = pyqtSignal()`
- ✅ Добавлена переменная `is_add_roi_clicked` для отслеживания состояния
- ✅ Добавлен метод `add_roi_clicked(flag)` для управления курсором
- ✅ Обновлен `mousePressEvent()` для обработки ROI кликов

### 4. Visualizer обновления
- ✅ Подключен сигнал `add_roi_signal` к слоту `open_roi_win`
- ✅ Подключен сигнал `add_roi_signal` к методу `add_roi_clicked`

### 5. ROIEditorDialog обновления
- ✅ Добавлен метод `set_image_from_pixmap(pixmap)` для установки изображений из источников
- ✅ Поддержка работы без масштабирования для изображений из активных источников

## Как это работает

### Пользовательский интерфейс
1. Пользователь выбирает "ROI Editor" из меню Tools
2. Появляется диалог с инструкциями
3. Пользователь кликает на активный источник
4. ROI Editor открывается с изображением из выбранного источника

### Техническая реализация
1. `MainWindow.open_roi_editor_window()` активирует режим выбора источника
2. `DoubleClickLabel.add_roi_clicked(True)` изменяет курсор на указатель
3. При клике на источник `emit_add_roi_signal()` отправляет сигнал
4. `VideoThread.add_roi_clicked()` активирует захват следующего кадра
5. `VideoThread.process_image()` отправляет изображение через `add_roi_signal`
6. `MainWindow.open_roi_win()` получает изображение и открывает ROI Editor
7. `ROIEditorDialog.set_image_from_pixmap()` устанавливает изображение
