# История развития ROI Editor

## Обзор

ROI Editor прошел через несколько этапов развития: от диалогового окна до полноценного независимого окна, с множеством исправлений проблем зависания и улучшений пользовательского интерфейса.

## Хронология изменений

### Этап 1: Преобразование Dialog в Window

**Проблема**: ROI Editor существовал как диалоговое окно (`ROIEditorDialog`), что ограничивало его функциональность.

**Решение**: Преобразование `ROIEditorDialog` в `ROIWindow` (наследник `QMainWindow`).

**Изменения**:
- Изменен базовый класс: `QDialog` → `QMainWindow`
- Убраны диалоговые методы: `setModal()`, `accept()`, `reject()`
- Добавлены окновые методы: меню, панель инструментов, splitter
- Перемещен из `dialogs/roi_editor_dialog.py` в `roi_window.py`
- Сохранен весь функционал: `ROIGraphicsView`, `ResizeHandle`, все методы работы с ROI

**Результат**: ROI Editor стал полноценным независимым окном, которое можно открывать из меню и правой панели главного окна.

### Этап 2: Удаление дублирования

**Проблема**: После преобразования остался старый `ROIEditorDialog`, что создавало дублирование кода.

**Решение**: Полное удаление `ROIEditorDialog` и использование только `ROIWindow`.

**Изменения**:
- Удален файл `evileye/visualization_modules/dialogs/roi_editor_dialog.py`
- Обновлены все импорты в `main_window.py`
- Заменена логика открытия: использование существующего окна вместо создания нового диалога

**Результат**: Единый код без дублирования, упрощенная поддержка.

### Этап 3: Исправление зависания при открытии

**Проблема**: ROI Editor зависал при открытии. В логах видно, что процесс останавливался после загрузки ROI из детектора.

**Причина**: В методе `set_rois_from_detector()` был вызов несуществующего метода `draw_scene()`:
```python
self.roi_canvas.draw_scene()  # ← ЭТОТ МЕТОД НЕ СУЩЕСТВУЕТ!
```

**Решение**:
- Удален вызов несуществующего метода
- Добавлены правильные вызовы обновления сцены:
```python
self._update_roi_list()
self.roi_canvas.scene.update()
self.roi_canvas.update()
```

**Результат**: ROI Editor открывается без зависания, ROI корректно загружаются из детектора.

### Этап 4: Комплексное исправление зависания

**Проблема**: После первого исправления остались дополнительные проблемы:
- Отсутствие родительского окна
- Отсутствие принудительного позиционирования
- Отсутствие принудительного обновления
- Недостаточное логирование

**Решение**:
1. Добавлено родительское окно: `self.roi_editor_window.setParent(self)`
2. Добавлено принудительное позиционирование:
```python
self.roi_editor_window.resize(1200, 800)
self.roi_editor_window.move(100, 100)
```
3. Добавлено принудительное обновление:
```python
self.roi_editor_window.update()
self.roi_editor_window.repaint()
```
4. Добавлено подробное логирование для диагностики

**Результат**: ROI Editor правильно позиционируется, показывается и обновляется.

### Этап 5: Финальное исправление зависания при загрузке

**Проблема**: ROI Editor зависал при загрузке ROI из детектора. Логи показывали зависание в цикле добавления ROI в canvas.

**Причины**:
1. Дублирование данных в `roi_data` - метод `add_roi_direct` добавлял данные, хотя они уже были установлены
2. Множественные обновления сцены - `self.scene.update()` вызывался после каждого ROI
3. Отсутствие обработки ошибок в критических методах

**Решение**:
1. Исправлено дублирование данных:
```python
if not hasattr(self, '_loading_from_config') or not self._loading_from_config:
    self.roi_data.append({"coords": coords, "color": color})
```

2. Оптимизировано обновление сцены:
```python
# БЫЛО: обновление сцены после каждого ROI
for entry in self.roi_canvas.roi_data:
    self.roi_canvas.add_roi_direct(...)

# СТАЛО: прямое создание ROI без промежуточных обновлений
for i, entry in enumerate(self.roi_canvas.roi_data):
    roi_item = self.roi_canvas._create_roi_item(...)
    if roi_item:
        self.roi_canvas.rois.append(roi_item)
# Обновляем сцену один раз в конце
self.roi_canvas.scene.update()
```

3. Добавлена обработка ошибок в критических методах

**Результат**: ROI Editor загружает ROI без зависания, оптимизированное обновление сцены.

## Использование

1. Запустить приложение: `evileye run configs/poly-cameras.json`
2. Открыть ROI Editor одним из способов:
   - Из меню: Edit → ROI Editor
   - Из правой панели: кнопка "ROI Editor"
   - По сигналу: при двойном клике на источнике
3. Редактировать ROI с помощью графического интерфейса
4. Изменения автоматически сохраняются в конфигурацию
