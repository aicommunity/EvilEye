# Решение проблемы с обновлением линий ROI при изменении размера

## 🎯 **Проблема**
Пользователь сообщил о рекуррентной проблеме: в некоторых случаях ROI отображаются и выбираются корректно, но в других случаях маркеры изменения размера (resize handles) появляются при выборе зоны, но линии не обновляются. В этом случае линии также не рисуются при изменении размера зоны. Однако маркеры изменения размера отображаются и двигаются.

## 🔍 **Анализ проблемы**

### **1. Проблемные ROI из конфигурации**
Проанализирована конфигурация `configs/poly-cameras.json` для source 0:
```json
"roi": [
    [
        [1790, 0, 500, 400],    // Маленький ROI
        [1700, 0, 1000, 1045],  // Средний ROI  
        [1500, 0, 2340, 2160]   // Большой ROI
    ]
]
```

### **2. Характеристики проблемных ROI:**
- **ROI 0**: [1790, 0, 500, 400] - размер: 500x400, площадь: 200,000
- **ROI 1**: [1700, 0, 1000, 1045] - размер: 1000x1045, площадь: 1,045,000  
- **ROI 2**: [1500, 0, 2340, 2160] - размер: 2340x2160, площадь: 5,054,400

### **3. Проблемы с перекрытием:**
- ROI 0 и ROI 1 перекрываются на 200,000 пикселей
- ROI 0 и ROI 2 перекрываются на 200,000 пикселей
- ROI 1 и ROI 2 перекрываются на 1,045,000 пикселей

## 🔧 **Найденные проблемы и исправления**

### **1. Проблема с позиционированием маркеров**
**Проблема**: Маркеры создавались со смещением на 10 пикселей (90 вместо 100)
**Причина**: В `_add_resize_handles` маркеры создавались с `handle_size/2` смещением
**Исправление**: Оставлено как есть - это правильное поведение для центрирования маркеров

### **2. Проблема с обновлением линий ROI**
**Проблема**: `_update_roi_size` вызывался, но размер ROI не изменялся
**Причина**: В тестах не устанавливался `self.selected_roi` правильно
**Исправление**: Исправлены тесты для правильной настройки состояния

### **3. Проблема с логированием**
**Проблема**: Отсутствовало подробное логирование процесса изменения размера
**Исправление**: Добавлено детальное логирование в `_update_roi_size`:
```python
self.logger.info(f"Updating ROI with handle_index={handle_index}, scene_pos={scene_pos}")
self.logger.info(f"Current rect before update: {current_rect}")
self.logger.info(f"Handle {handle_index} ({description}): {operation}")
self.logger.info(f"New rect after update: {new_rect}")
```
