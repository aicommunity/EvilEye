# Решение проблемы с базой данных EvilEye

## 🎯 Проблема

При запуске EvilEye возникало предупреждение:
```
WARNING - Database enabled but unavailable. Working without database. Reason: 'image_dir'
```

Это приводило к тому, что:
- ❌ Кнопка Configuration History была отключена
- ❌ Система истории конфигураций была недоступна
- ❌ EvilEye работал только в режиме JSON журнала

## ✅ Решение

### 1. **Добавлена секция database в конфигурацию**

В файл `configs/poly-cameras.json` добавлена секция:
```json
"database": {
    "type": "sqlite",
    "database_name": "/home/user/EvilEye/EvilEyeData/evileye_test.db",
    "images_dir": "EvilEyeData/images",
    "preview_height": 200,
    "preview_width": 200
}
```

### 2. **Создана тестовая SQLite база данных**

- **Путь:** `/home/user/EvilEye/EvilEyeData/evileye_test.db`
- **Таблицы:** jobs, projects, objects
- **Тестовые данные:** Добавлена тестовая конфигурация

### 3. **Создана директория для изображений**

- **Путь:** `/home/user/EvilEye/EvilEyeData/images`
- **Назначение:** Хранение изображений для базы данных

## 🚀 Результат

### Теперь доступно:
- ✅ **База данных подключена** и работает
- ✅ **Configuration History активна** в главном окне
- ✅ **Все функции истории конфигураций** доступны
- ✅ **Автоматическое сохранение** конфигураций при запуске

## 📁 Созданные файлы

1. **`EvilEyeData/evileye_test.db`** - SQLite база данных
2. **`EvilEyeData/images/`** - директория для изображений
3. **`configs/poly-cameras.json.backup`** - резервная копия конфигурации
4. **`setup_test_database.py`** - скрипт настройки
5. **`DATABASE_SETUP_GUIDE.md`** - руководство по настройке

## 🔧 Как использовать

### Запуск EvilEye с базой данных:
```bash
python3 evileye/process.py --config configs/poly-cameras.json --gui
```

### Доступ к Configuration History:
1. **Главное окно:** Settings → Configuration History
2. **Окно настроек:** Open → Open history
3. **Toolbar:** Кнопки Configuration History
