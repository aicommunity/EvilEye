# ROI Editor Fixes Summary

## Исправленные проблемы

### 1. ✅ Zone Editor в главном окне
**Проблема**: При клике на Zone Editor показывался новый ZoneEditorDialog вместо старого ZoneWindow.

**Решение**: 
- Обновлен метод `open_zone_editor_window()` в MainWindow
- Теперь используется старый `self.zone_window` вместо нового `ZoneEditorDialog`
- Сохранена оригинальная функциональность Zone Window

### 2. ✅ Возможность установки ROI мышкой
**Проблема**: В ROI редакторе не было возможности устанавливать ROI мышкой на изображении.

**Решение**:
- Исправлена логика обработки мыши в `ROICanvas`
- Упрощена система рисования - только прямоугольники
- Клик и перетаскивание для создания ROI
- Автоматическое создание ROI при отпускании мыши

### 3. ✅ Упрощение ROI редактора
**Проблема**: ROI редактор был слишком сложным с названиями и поддержкой полигонов.

**Решение**:
- Убрана поддержка полигонов - только прямоугольники
- Убраны названия ROI - используются автоматические номера (ROI_1, ROI_2, ...)
- Упрощен UI - убраны ненужные элементы управления
- Убрана возможность ручного добавления и переименования ROI

## Новый пользовательский интерфейс

### Упрощенный UI ROI редактора:
- **Загрузка изображения** - кнопка для загрузки файла
- **Настройки рисования** - только выбор цвета
- **Список ROI** - показывает ROI_1, ROI_2, ... с координатами
- **Управление** - только кнопка "Удалить"
- **Настройки** - только "Показывать номера"

### Инструкции:
- Кликните и перетащите для создания прямоугольного ROI
- ROI создаются автоматически при отпускании мыши

## Как использовать

1. **Создание ROI**: Кликните и перетащите мышкой на изображении
2. **Удаление ROI**: Выберите ROI в списке и нажмите "Удалить"
3. **Изменение цвета**: Выберите цвет в выпадающем списке
4. **Показ номеров**: Включите/выключите отображение номеров ROI

## Обратная совместимость

- ✅ Сохранена поддержка старого формата данных с `coords`
- ✅ Все существующие ROI продолжают работать
- ✅ Экспорт/импорт ROI в JSON формате

ROI редактор теперь:
