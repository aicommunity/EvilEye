# ROI Editor Update Summary

## Обзор изменений

ROI Editor был обновлен с использованием логики Zone Editor для обеспечения единообразия и расширенной функциональности.

## Ключевые улучшения

### 1. Поддержка полигонов
- ✅ Добавлена поддержка рисования полигонов (в дополнение к прямоугольникам)
- ✅ Двойной клик для завершения полигона
- ✅ Интерактивное рисование с предварительным просмотром

### 2. Улучшенный пользовательский интерфейс
- ✅ Группа настроек рисования с выбором типа ROI
- ✅ Выбор цвета для ROI
- ✅ Настройки отображения (показ названий, заливка)
- ✅ Инструкции для пользователя

### 3. Расширенная функциональность
- ✅ Поддержка двух типов ROI: rectangle и polygon
- ✅ Улучшенное управление ROI (переименование, удаление)
- ✅ Совместимость со старым форматом данных (coords)
- ✅ Поддержка нового формата данных (points)

### 4. Технические улучшения
- ✅ Обновленная структура данных ROI
- ✅ Улучшенная обработка масштабирования координат
- ✅ Более гибкая система рисования
- ✅ Лучшая обработка событий мыши

## Структура данных ROI

### Старый формат (поддерживается)
```json
{
  "name": "ROI_1",
  "coords": [x1, y1, x2, y2]
}
```

### Новый формат
```json
{
  "name": "ROI_1",
  "type": "rectangle",
  "points": [[x1, y1], [x2, y2]]
}
```

```json
{
  "name": "ROI_2", 
  "type": "polygon",
  "points": [[x1, y1], [x2, y2], [x3, y3], ...]
}
```

## Инструкции по использованию

### Рисование прямоугольников
1. Выберите тип "rectangle"
2. Кликните и перетащите для создания прямоугольника

### Рисование полигонов
1. Выберите тип "polygon"
2. Кликайте для добавления точек
3. Двойной клик для завершения полигона

### Управление ROI
- Переименование: выберите ROI в списке и нажмите "Переименовать"
- Удаление: выберите ROI в списке и нажмите "Удалить"
- Экспорт/импорт: используйте соответствующие кнопки
