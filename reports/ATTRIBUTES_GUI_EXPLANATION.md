# Объяснение цифр в GUI атрибутов

## Формат отображения в GUI

```
hard_hat: exists (0.78, 1500ms)
no_hard_hat: lost (0.12, 0ms)
```

## Расшифровка всех цифр

### 1. **Состояние атрибута** (`state`)
- **`none`** - атрибут не обнаружен или сброшен
- **`exists`** - атрибут подтвержден и активен
- **`lost`** - атрибут был обнаружен, но потерян

### 2. **Сглаженное доверие** (`confidence_smooth`) - первое число в скобках
- **Что это**: EMA-сглаженное значение confidence от YOLO детекции
- **Диапазон**: 0.00 - 1.00
- **Как работает**: 
  - При детекции: `new_confidence = α * yolo_confidence + (1-α) * old_confidence`
  - При отсутствии: **НЕ изменяется** (сохраняется последнее значение)
- **α (ema_alpha)**: 0.7 (настраивается в конфигурации)
- **Преимущество**: Стабильность - confidence не затухает при временном отсутствии детекции

### 3. **Общее время присутствия** (`total_time_ms`) - второе число в скобках
- **Что это**: Общее время в миллисекундах, когда атрибут был в состоянии `exists`
- **Как накапливается**: `total_time_ms += dt_ms` при каждой детекции
- **Сбрасывается**: При переходе в состояние `none`

## Дополнительные метрики (не отображаются в GUI)

### 4. **Количество кадров** (`frames_present`)
- **Что это**: Количество кадров с детекцией атрибута
- **Увеличивается**: При каждой успешной детекции
- **Сбрасывается**: При переходе в состояние `none`

### 5. **Время отсутствия** (`no_detect_time_ms`)
- **Что это**: Время в миллисекундах с последней детекции
- **Увеличивается**: При отсутствии детекции
- **Сбрасывается**: При новой детекции

### 6. **Количество входов** (`enter_count`)
- **Что это**: Сколько раз атрибут переходил в состояние `exists`
- **Увеличивается**: При переходе `none` → `exists` или `lost` → `exists`

### 7. **Временные метки**
- **`enter_ts`**: Timestamp входа в состояние `exists`
- **`last_seen_ts`**: Timestamp последней детекции

## Логика состояний

### Переходы состояний:

```
none → exists: total_time_ms >= confirm_time_ms
exists → lost: no_detect_time_ms >= min_time_ms  
lost → exists: total_time_ms >= confirm_time_ms (при новой детекции)
lost → none: no_detect_time_ms >= confirm_time_ms
```

### Пороги времени (из вашей конфигурации):

```json
"time_thresholds": {
  "hard_hat": {
    "min_time_ms": 30,      // Минимум для перехода exists → lost
    "confirm_time_ms": 60   // Минимум для перехода none → exists
  }
}
```

## Примеры интерпретации

### Пример 1: `hard_hat: exists (0.78, 1500ms)`
- **Состояние**: Атрибут подтвержден и активен
- **Доверие**: 78% (высокое, стабильное)
- **Время**: 1.5 секунды непрерывного присутствия

### Пример 2: `no_hard_hat: lost (0.12, 0ms)`
- **Состояние**: Атрибут был обнаружен, но потерян
- **Доверие**: 12% (низкое, затухает)
- **Время**: 0ms (сброшено при переходе в `lost`)

### Пример 3: `backpack: none (0.00, 0ms)`
- **Состояние**: Атрибут не обнаружен
- **Доверие**: 0% (полностью затухло)
- **Время**: 0ms (сброшено)

## Цветовая схема

- **Серый** (`none`): Атрибут не обнаружен
- **Зеленый** (`exists`): Атрибут подтвержден
- **Желтый** (`lost`): Атрибут потерян, но еще не сброшен

## Настройка чувствительности

### Быстрая реакция (ваша текущая настройка):
```json
"min_time_ms": 30,      // Быстро теряет атрибут
"confirm_time_ms": 60   // Быстро подтверждает атрибут
```

### Стабильная работа:
```json
"min_time_ms": 600,     // Стабильно держит атрибут
"confirm_time_ms": 1500 // Требует больше времени для подтверждения
```

## Масштабирование шрифта

### Адаптивный размер текста

Размер текста атрибутов автоматически масштабируется в зависимости от разрешения изображения:

- **640x480**: font_scale ≈ 0.24 (маленький текст)
- **1280x720**: font_scale ≈ 0.36 (средний текст)  
- **1920x1080**: font_scale ≈ 0.53 (базовый размер)
- **2560x1440**: font_scale ≈ 0.71 (большой текст)
- **3840x2160**: font_scale ≈ 1.07 (очень большой текст)

### Настройка масштабирования

```json
"text_config": {
  "font_scale_method": "resolution_based",  // или "simple"
  "base_resolution": [1920, 1080],
  "font_size_pt": 12
}
```

### Преимущества

- ✅ **Читаемость**: Атрибуты одинаково читаемы на всех разрешениях
- ✅ **Пропорциональность**: Размер текста пропорционален размеру изображения
- ✅ **Автоматичность**: Не требует ручной настройки для каждого разрешения
