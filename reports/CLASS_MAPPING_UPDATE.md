# Обновление системы классов: class_names → class_mapping

## Обзор изменений

Поле `self.class_names` в `controller.py` было заменено на `self.class_mapping` как словарь `class_name: class_id` для более гибкого управления классами объектов.

## Основные изменения

### 1. Controller.py
- **Заменено**: `self.class_names = [...]` (список)
- **На**: `self.class_mapping = {"person": 0, "bicycle": 1, ...}` (словарь)
- **Добавлены методы**:
  - `get_class_name(class_id)` - получение имени класса по ID
  - `get_class_id(class_name)` - получение ID класса по имени
  - `get_class_names_list()` - получение списка имен классов в порядке ID

### 2. Utils.py
- **Обновлена функция**: `draw_boxes()` - теперь принимает `class_mapping` вместо `model_names`
- **Обновлена функция**: `draw_boxes_tracking()` - добавлен параметр `class_mapping`
- **Добавлена функция**: `get_class_name_from_mapping()` - вспомогательная функция для получения имени класса

### 3. VideoThread.py
- **Добавлен параметр**: `class_mapping` в конструктор
- **Обновлен вызов**: `draw_boxes_tracking()` с передачей `class_mapping`

### 4. Visualizer.py
- **Добавлен атрибут**: `self.class_mapping`
- **Обновлено создание**: `VideoThread` с передачей `class_mapping`

### 5. Objects_handler.py и ROI_feeder.py
- **Обновлена логика**: проверки первичных классов с использованием `class_mapping`
- **Добавлен fallback**: к старому формату для обратной совместимости

### 6. Labeling_manager.py
- **Обновлена функция**: `_get_class_name()` для использования `class_mapping`

## Обратная совместимость

Система поддерживает оба формата:
1. **Старый формат**: `"class_names": ["person", "bicycle", ...]`
2. **Новый формат**: `"class_mapping": {"person": 0, "bicycle": 1, ...}`

При загрузке конфигурации:
- Если найден `class_mapping` - используется он
- Если найден `class_names` - автоматически конвертируется в `class_mapping`
- Если ничего не найдено - используются значения по умолчанию

## Примеры использования

### Новый формат конфигурации
```json
{
  "controller": {
    "class_mapping": {
      "person": 0,
      "bicycle": 1,
      "car": 2,
      "motorcycle": 3
    }
  }
}
```

### Программное использование
```python
# Получение имени класса по ID
class_name = controller.get_class_name(0)  # "person"

# Получение ID класса по имени
class_id = controller.get_class_id("person")  # 0

# Получение списка всех имен классов
class_names = controller.get_class_names_list()  # ["person", "bicycle", ...]
```

## Преимущества нового подхода

1. **Гибкость**: Можно задавать произвольные ID для классов
2. **Читаемость**: Явное соответствие между именами и ID
3. **Расширяемость**: Легко добавлять новые классы
4. **Обратная совместимость**: Старые конфигурации продолжают работать
5. **Отображение в GUI**: Теперь показываются имена классов вместо ID

## Файлы, требующие обновления конфигураций

Если у вас есть существующие конфигурации с `class_names`, они будут автоматически конвертированы. Для новых проектов рекомендуется использовать формат `class_mapping`.

Пример обновленной конфигурации см. в файле `configs/example_class_mapping.json`.
