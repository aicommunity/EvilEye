# Обновление отображения атрибутов в GUI

## Обзор

Обновлено отображение атрибутов в GUI для показа расширенной информации, включая суммарное время атрибута и процент времени обнаружения.

## Новый формат отображения

### Старый формат
```
attr_name: (confidence, total_time_ms)
```

### Новый формат
```
attr_name: state (confidence, summary_time_ms, found_ratio%)
```

## Примеры отображения

### Пример 1: Стабильно присутствующий атрибут
```
hard_hat: exists (0.85, 1500ms, 80.0%)
```
- **Состояние**: `exists` - атрибут стабильно присутствует
- **Доверие**: `0.85` - высокое EMA-сглаженное значение
- **Суммарное время**: `1500ms` - положительное время (найдено больше, чем потеряно)
- **Found ratio**: `80.0%` - 80% времени атрибут был обнаружен

### Пример 2: Нестабильный атрибут
```
no_hard_hat: lost (0.12, 0ms, 20.0%)
```
- **Состояние**: `lost` - атрибут нестабилен
- **Доверие**: `0.12` - низкое значение (затухает)
- **Суммарное время**: `0ms` - время потери превышает время обнаружения
- **Found ratio**: `20.0%` - только 20% времени атрибут был обнаружен

### Пример 3: Отсутствующий атрибут
```
safety_vest: none (0.00, 0ms, 6.0%)
```
- **Состояние**: `none` - атрибут практически отсутствует
- **Доверие**: `0.00` - полностью затухло
- **Суммарное время**: `0ms` - время потери значительно превышает время обнаружения
- **Found ratio**: `6.0%` - только 6% времени атрибут был обнаружен

## Реализация

### Обновленная логика отображения

```python
# Получаем новые поля для улучшенного отображения
total_found_time = attr_data.get('total_found_time_ms', 0)
total_lost_time = attr_data.get('total_lost_time_ms', 0)
found_ratio = attr_data.get('found_ratio', 0.0)

# Рассчитываем суммарное время (или ноль если < 0)
summary_time = max(0, total_found_time - total_lost_time)

# Create attribute text with enhanced information
color = state_colors.get(state, (128, 128, 128))
attr_text = f"{attr_name}: {state} ({confidence:.2f}, {summary_time}ms, {found_ratio:.1%})"
```

### Расчет суммарного времени

```python
# Суммарное время = max(0, время_обнаружения - время_потери)
summary_time = max(0, total_found_time - total_lost_time)
```

**Логика расчета**:
- Если `total_found_time > total_lost_time` → положительное время
- Если `total_found_time < total_lost_time` → ноль (не показываем отрицательное время)
- Если `total_found_time == total_lost_time` → ноль

## Интерпретация данных

### Суммарное время (summary_time)

| Значение | Интерпретация |
|----------|---------------|
| `> 0ms` | Атрибут больше времени присутствовал, чем отсутствовал |
| `0ms` | Атрибут больше времени отсутствовал, чем присутствовал |

### Found ratio (процент времени обнаружения)

| Диапазон | Интерпретация |
|----------|---------------|
| `80-100%` | Атрибут стабильно присутствует |
| `50-80%` | Атрибут часто присутствует |
| `30-50%` | Атрибут нестабилен |
| `10-30%` | Атрибут редко присутствует |
| `0-10%` | Атрибут практически отсутствует |

### Состояние атрибута

| Состояние | Описание |
|-----------|----------|
| `exists` | Атрибут стабильно присутствует |
| `lost` | Атрибут нестабилен, частично присутствует |
| `none` | Атрибут практически отсутствует |

## Цветовая схема

### Цвета состояний

- **Серый** (`none`): Атрибут не обнаружен
- **Зеленый** (`exists`): Атрибут подтвержден
- **Желтый** (`lost`): Атрибут потерян, но еще не сброшен

### Визуальная индикация

- **Цвет текста**: Зависит от состояния атрибута
- **Фон**: Полупрозрачный для лучшей читаемости
- **Размер шрифта**: 0.5x от основного шрифта объектов

## Преимущества нового отображения

### ✅ Расширенная информация

1. **Состояние**: Показывает текущее состояние атрибута
2. **Доверие**: EMA-сглаженное значение confidence
3. **Суммарное время**: Показывает баланс времени обнаружения/потери
4. **Found ratio**: Процент времени обнаружения

### ✅ Лучшая аналитика

1. **Статистика**: Можно анализировать паттерны поведения атрибутов
2. **Тренды**: Видно, как атрибуты ведут себя во времени
3. **Качество**: Можно оценить надежность детекции атрибутов

### ✅ Улучшенная отладка

1. **Прозрачность**: Все метрики доступны для анализа
2. **Контекст**: Понимание того, почему атрибут в определенном состоянии
3. **Мониторинг**: Можно отслеживать производительность системы
