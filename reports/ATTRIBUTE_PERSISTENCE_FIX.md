# Исправление персистентности состояний атрибутов

## Проблема

Состояния атрибутов часто сбрасывались для объектов, которые не были потеряны (или потеряны только на одном кадре). Это происходило из-за неправильной логики в `ObjectsHandler._handle_active`.

## Анализ проблемы

### Старая логика (проблемная)

```python
# В ObjectsHandler._handle_active
pred = self._attr_pending.pop(getattr(obj.track, 'track_id', None), None)
if pred:
    for attr_name, conf in pred.items():
        self.attr_manager.update(obj.track.track_id, attr_name, True, float(conf), now_ts, dt_ms)
else:
    # ❌ ПРОБЛЕМА: Обновляла все атрибуты как False при отсутствии предсказаний
    for attr_name, st in self.attr_manager.get_states(obj.track.track_id).items():
        self.attr_manager.update(obj.track.track_id, attr_name, False, 0.0, now_ts, dt_ms)
```

### Проблемы старой логики

1. **Сброс состояний**: При отсутствии предсказаний все атрибуты обновлялись как `False`
2. **Потеря EMA**: `confidence_smooth` сбрасывался при каждом отсутствии предсказаний
3. **Неправильные переходы**: Атрибуты переходили в `lost` → `none` слишком быстро
4. **Нестабильность**: Состояния атрибутов "мерцали" между кадрами

## Решение

### Новая логика (исправленная)

```python
# В ObjectsHandler._handle_active
pred = self._attr_pending.pop(getattr(obj.track, 'track_id', None), None)
if pred:
    for attr_name, conf in pred.items():
        self.attr_manager.update(obj.track.track_id, attr_name, True, float(conf), now_ts, dt_ms)
# ✅ ИСПРАВЛЕНО: Не обновляем атрибуты при отсутствии предсказаний
# Состояния атрибутов сохраняются между кадрами
```

### Дополнительные улучшения

#### 1. Исправлен `_ensure_all_attributes_present`

```python
# ❌ СТАРАЯ ВЕРСИЯ: Жестко заданные атрибуты
attrs = getattr(self.attr_manager, '_configured_attrs', ['hard_hat', 'no_hard_hat'])

# ✅ НОВАЯ ВЕРСИЯ: Только настроенные атрибуты
attrs = getattr(self.attr_manager, '_configured_attrs', [])
if not attrs:
    return
```

#### 2. Улучшена структура данных атрибутов

```python
# ✅ Правильная структура для новых атрибутов
obj.attributes[attr_name] = {
    'name': attr_name,  # Вместо 'attr_name'
    'state': 'none',
    'confidence_smooth': 0.0,
    'frames_present': 0,
    'total_time_ms': 0,
    'no_detect_time_ms': 0,
    'enter_count': 0,
    'enter_ts': None,
    'last_seen_ts': None
    # Убрано: 'ema_alpha' (не нужно в объекте)
}
```

## Результаты исправления

### ✅ Преимущества

1. **Стабильность**: Состояния атрибутов сохраняются между кадрами
2. **EMA-сглаживание**: `confidence_smooth` не сбрасывается при отсутствии детекции
3. **Правильные переходы**: Атрибуты переходят в `lost` → `none` только по таймаутам
4. **Производительность**: Меньше ненужных обновлений состояний

## Архитектурные улучшения

### 1. Разделение ответственности

- **AttributeManager**: Управляет состояниями атрибутов
- **ObjectsHandler**: Сохраняет снимки состояний в объекты
- **GUI**: Отображает текущие состояния

### 2. Устойчивость к ошибкам

- Отсутствие предсказаний не сбрасывает состояния
- EMA-сглаживание работает стабильно
- Переходы состояний происходят только по таймаутам

### 3. Производительность

- Меньше ненужных обновлений
- Состояния кэшируются в объектах
- EMA-сглаживание оптимизировано

## Заключение

Исправление персистентности состояний атрибутов решает ключевую проблему нестабильности системы атрибутов. Теперь:

- ✅ Состояния атрибутов сохраняются между кадрами
- ✅ EMA-сглаживание работает корректно
- ✅ Переходы состояний происходят только по таймаутам
- ✅ Система атрибутов работает стабильно и предсказуемо
