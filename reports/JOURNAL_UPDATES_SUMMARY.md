## Выполненные изменения

### ✅ 1. Исправлено отображение source_name
**Проблема**: В колонке Source отображалось `source_1`, `source_2` вместо `Cam1`, `Cam2`

**Решение**: 
- Обновлена логика отображения в `_reload_table`
- Добавлена проверка: если `source_name` пустой, используется `f"Cam{source_id}"`
- Теперь корректно отображается `Cam1`, `Cam2`, `Cam3` и т.д.

### ✅ 2. Изменена структура таблицы на базу данных
**Проблема**: Таблица не соответствовала структуре базы данных журнала

**Решение**:
- Изменены заголовки колонок: `['Event', 'Time', 'Time lost', 'Information', 'Preview', 'Lost preview']`
- Структура теперь соответствует `DatabaseJournalWindow`
- Колонки: Event, Time, Time lost, Information, Preview, Lost preview

### ✅ 3. Группировка found и lost событий в одной строке
**Проблема**: Found и lost события отображались в разных строках

**Решение**:
- Добавлена группировка событий по `object_id`
- В одной строке теперь показывается:
  - **Event**: `Object {object_id}`
  - **Time**: время обнаружения (found event)
  - **Time lost**: время потери (lost event)
  - **Information**: `Object Id={id}; class: {class}; conf: {confidence}`
  - **Preview**: изображение обнаружения
  - **Lost preview**: изображение потери

### ✅ 4. Добавлено обновление в реальном времени
**Проблема**: Журнал не обновлялся автоматически

**Решение**:
- Добавлен `QTimer` с интервалом 5 секунд
- Автоматическое обновление таблицы каждые 5 секунд
- Таймер останавливается при закрытии окна

### ✅ 5. Обновлен ImageDelegate
**Проблема**: Bounding box данные не передавались правильно

**Решение**:
- Bounding box данные теперь сохраняются в `Qt.ItemDataRole.UserRole`
- ImageDelegate получает данные из текущей колонки
- Поддержка разных форматов bounding box (массив и словарь)
- Правильное масштабирование относительно размеров изображения
