# UML Diagram Generation

Скрипты для генерации статических UML диаграмм системы EvilEye.

## Установка зависимостей

```bash
pip install graphviz plantuml
sudo apt install graphviz  # On Ubuntu/Debian
```

## Генерация диаграмм

### Базовая генерация

```bash
python generate_uml_diagrams.py
```

### Расширенная генерация

```bash
python generate_enhanced_uml.py
```

## Результаты

Сгенерированные диаграммы сохраняются в папку `docs/uml/`:

- **PNG файлы**: Статические изображения диаграмм классов, архитектуры и потоков данных
- **PlantUML файлы** (`.puml`): Исходные файлы для просмотра и редактирования

## Просмотр диаграмм

- **PNG файлы**: Откройте в любом просмотрщике изображений
- **PlantUML файлы**: Используйте расширение VS Code или онлайн-просмотрщик на plantuml.com

## Настройка

- Измените цвета пакетов в словаре `package_colors`
- Модифицируйте анализ классов в методе `analyze_class`
- Добавьте новые типы диаграмм в классы генераторов

## Примечание

Статические UML диаграммы дополняют интерактивные Mermaid диаграммы в [ARCHITECTURE.md](../../docs/ARCHITECTURE.md). Для детального изучения архитектуры рекомендуется использовать интерактивные диаграммы в ARCHITECTURE.md.
