## Рекомендации

1. **Добавить принудительный GC после cleanup**: В критических местах (после `clear()`, `release()`) можно добавить `gc.collect()` для немедленного освобождения памяти.

2. **Мониторинг в production**: Использовать `scripts/memory_profiler.py` для долгосрочного мониторинга в production окружении.

3. **Периодическая очистка**: Для долгосрочной работы рекомендуется периодически вызывать `gc.collect()` в неактивные моменты.
