# Руководство пользователя: История конфигураций EvilEye

## 🎯 Что это такое?

Система истории конфигураций EvilEye позволяет:
- **Просматривать** все ранее запущенные конфигурации
- **Восстанавливать** любую конфигурацию из истории
- **Сравнивать** разные конфигурации между собой
- **Экспортировать** историю для анализа

## ⚙️ Требования

### Обязательные условия:
- ✅ **База данных должна быть включена** в конфигурации
- ✅ **DatabaseJournalWindow** должен быть активен (не JSON режим)
- ✅ **Конфигурации должны быть запущены** хотя бы один раз

### Как проверить режим базы данных:
1. Запустите EvilEye
2. Если в логах есть сообщения о подключении к базе данных - режим БД активен
3. Если есть предупреждения о JSON режиме - нужно включить БД

## 🚀 Как использовать

### 1. Открытие истории конфигураций

**Способ 1: Через меню**
1. В главном окне EvilEye выберите **Settings → Configuration History**

**Способ 2: Через toolbar**
1. Нажмите кнопку **Configuration History** в правой панели инструментов

**Способ 3: Через ConfigurerMainWindow**
1. Откройте окно настроек (Settings)
2. Нажмите кнопку **"Open history"** в toolbar

### 2. Просмотр истории

В окне истории вы увидите:
- **Project ID** - идентификатор проекта
- **Job ID** - идентификатор задания
- **Configuration ID** - идентификатор конфигурации
- **Time** - время создания
- **Configuration JSON** - содержимое конфигурации

**Фильтрация:**
- Используйте поля **Start Time** и **Finish Time** для фильтрации по дате
- Нажмите **Search** для применения фильтра
- Нажмите **Reset** для сброса фильтра

### 3. Восстановление конфигурации

1. **Выберите конфигурацию** в списке (один клик)
2. Нажмите **"Восстановить конфигурацию"**
3. В диалоге восстановления:
   - Выберите **путь для восстановления** (кнопка "Обзор...")
   - Отметьте **"Создать резервную копию"** (рекомендуется)
   - Отметьте **"Перезапустить pipeline"** при необходимости
4. Нажмите **"Восстановить"**

**Что происходит:**
- Текущий файл конфигурации сохраняется как backup
- Выбранная конфигурация записывается в указанный файл
- При необходимости можно перезапустить приложение

### 4. Сравнение конфигураций

1. **Выберите 2 конфигурации** (Ctrl+Click для множественного выбора)
2. Нажмите **"Сравнить конфигурации"**
3. В диалоге сравнения:
   - Выберите конфигурации из выпадающих списков
   - Нажмите **"Сравнить"**
   - Просмотрите различия в дереве
   - При необходимости экспортируйте результаты

**Типы различий:**
- 🔴 **Различие типов** - разные типы данных
- 🟡 **Отсутствует в первой** - параметр есть только во второй конфигурации
- 🟡 **Отсутствует во второй** - параметр есть только в первой конфигурации
- 🟠 **Различие значений** - одинаковые параметры с разными значениями

### 5. Экспорт истории

1. Нажмите **"Экспорт истории"**
2. Выберите путь для сохранения JSON файла
3. История будет экспортирована со всеми метаданными

**Содержимое экспорта:**
- Временные метки экспорта
- Фильтры, примененные к истории
- Полные данные всех конфигураций
- Статистика по количеству записей

## 🔧 Устранение проблем

### Проблема: "База данных недоступна"
**Причина:** EvilEye работает в режиме JSON журнала
**Решение:** 
1. Включите использование базы данных в конфигурации
2. Перезапустите приложение
3. Убедитесь, что параметры БД корректны

### Проблема: "Configuration History requires database mode"
**Причина:** Кнопка Configuration History отключена
**Решение:**
1. Проверьте подключение к базе данных
2. Убедитесь, что DatabaseJournalWindow активен
3. Перезапустите приложение

### Проблема: "Не удалось получить информацию о конфигурации"
**Причина:** Конфигурация не найдена в базе данных
**Решение:**
1. Убедитесь, что конфигурация была запущена хотя бы один раз
2. Проверьте, что база данных содержит данные
3. Попробуйте обновить список (Reset фильтра)

### Проблема: Ошибка при восстановлении конфигурации
**Причина:** Проблемы с правами доступа или путем
**Решение:**
1. Проверьте права на запись в выбранную директорию
2. Убедитесь, что путь существует
3. Попробуйте выбрать другой путь

## 💡 Советы по использованию

### Лучшие практики:
1. **Всегда создавайте backup** при восстановлении конфигураций
2. **Используйте описательные имена** для экспортированных файлов
3. **Регулярно экспортируйте историю** для резервного копирования
4. **Сравнивайте конфигурации** перед внесением изменений

### Организация конфигураций:
- **Используйте версионирование** в именах файлов (config_v1.json, config_v2.json)
- **Создавайте тематические папки** для разных типов конфигураций
- **Документируйте изменения** в комментариях к конфигурациям

### Производительность:
- **Ограничивайте период фильтрации** для больших объемов данных
- **Используйте экспорт** для работы с большими историями
- **Регулярно очищайте старые записи** (если настроено)

## 📞 Поддержка

При возникновении проблем:
1. Проверьте логи EvilEye на наличие ошибок
2. Убедитесь, что все требования выполнены
3. Попробуйте перезапустить приложение
4. Обратитесь к документации EvilEye
