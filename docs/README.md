# Документация EvilEye

Добро пожаловать в документацию системы видеонаблюдения EvilEye! Здесь вы найдете все необходимые руководства, инструкции и справочные материалы.

## Содержание

### 📚 Установка и настройка

- **[Руководство по настройке базы данных](DATABASE_SETUP_GUIDE.md)** - Подробное руководство по настройке PostgreSQL базы данных для EvilEye
- **[Команда deploy](CLI_DEPLOY_COMMAND.md)** - Использование команды `evileye deploy` для развертывания системы
- **[Руководство по конфигурациям](CONFIGURATION_GUIDE.md)** - Полное описание структуры конфигурационных файлов, всех параметров и примеры конфигураций

### Архитектура системы

- **[Архитектура системы](ARCHITECTURE.md)** - Полное описание архитектуры на 7 уровнях абстракции (CLI, Controller, Pipeline, Video, Objects, Events, Database) с интерактивными Mermaid диаграммами и статическими UML диаграммами
- **[Архитектура Pipeline](PIPELINE_ARCHITECTURE.md)** - Описание архитектуры pipeline, базовых классов и способов создания собственных pipeline

### Функциональность

- **[Система детекции атрибутов](ATTRIBUTES_DETECTION_README.md)** - Детекция и трекинг атрибутов объектов (каска, рюкзак и т.д.)

- **[Система рендеринга текста](TEXT_RENDERING_SYSTEM.md)** - Адаптивный рендеринг текста с поддержкой различных разрешений
- **[История конфигураций](CONFIG_HISTORY_USER_GUIDE.md)** - Руководство пользователя по работе с историей конфигураций

- **[Использование GStreamer для видео](VideoCaptureGStreamer_Usage.md)** - Настройка и использование GStreamer для захвата видео с IP-камер, USB-камер и файлов
- **[Использование GStreamer для последовательностей изображений](ImageSequence_GStreamer_Usage.md)** - Обработка последовательностей изображений через GStreamer
- **[Создание конфигураций](CREATE_SCRIPT_README.md)** - Использование команды `evileye create` для создания новых конфигураций

## Быстрая навигация

### Для новых пользователей

1. Начните с [установки и настройки базы данных](DATABASE_SETUP_GUIDE.md)
2. Изучите [команду deploy](CLI_DEPLOY_COMMAND.md) для развертывания системы
3. Ознакомьтесь с [руководством по конфигурациям](CONFIGURATION_GUIDE.md) для понимания структуры конфигурационных файлов
4. Изучите [создание конфигураций](CREATE_SCRIPT_README.md) для создания собственных конфигураций

### Для разработчиков

1. Изучите [архитектуру системы](ARCHITECTURE.md) для понимания общей структуры на всех уровнях
2. Изучите [архитектуру Pipeline](PIPELINE_ARCHITECTURE.md) для деталей реализации pipeline
3. Просмотрите [архитектуру системы](ARCHITECTURE.md) для понимания структуры системы на всех уровнях
4. Ознакомьтесь с [руководством по рефакторингу GUI](GUI_REFACTORING_GUIDE.md)

### Для интеграторов

1. Изучите [использование GStreamer](VideoCaptureGStreamer_Usage.md) для различных источников видео
2. Ознакомьтесь с [системой детекции атрибутов](ATTRIBUTES_DETECTION_README.md)
3. Изучите [систему меток объектов](LABELING_SYSTEM_README.md) для экспорта данных
