# Проверка выполнения плана CLI pipeline

Дата: 13 октября 2026 года. Проверена реализация последнего плана
«Просмотр и конфигурирование пайплайнов в CLI EvilEye».

| Пункт | Результат проверки |
| --- | --- |
| `pipeline inspect` | Конфиг и сохранённый запуск; tree, edges, DOT, JSON; терминальный watch |
| `plugin list` | Установленные модули, kind, стадии, режимы исполнения, наличие схемы |
| Топология | Surveillance с fan-out, extend/replace и отдельной event-веткой; Declarative; Capture с единственным OpenCV-источником |
| Сторонние pipeline | Provider вызывается без создания pipeline; отсутствие provider явно обозначается как непрозрачная топология |
| Схемы и формы | Метаданные и схемы всех 17 канонических встроенных модулей; алиасы, поля конфигов репозитория, вложенные объекты, списки, enum и ограничения |
| Строгие сторонние схемы | Служебные поля проверяются отдельно; вложенный `config` редактируется без переноса полей; фабрика получает только свои параметры |
| Runtime | Статистика стадий и отдельных экземпляров; короткие и полные ID сопоставляются без смешивания одинаковых модулей; статусы и явная свежесть телеметрии |
| Мастер | Выбор, добавление, удаление, перестановка и настройка модулей; параметры fan-out и стадии результата; сохранение старых declarative-стадий и неизвестных полей |
| Сохранение | Diff, явное подтверждение, атомарная запись, последние 10 резервных копий; неизменённый конфиг не перезаписывается |
| Ошибки и отмена | Повтор ввода; EOF и Ctrl-C; некорректная конфигурация не сохраняется; stopped/missing snapshot завершает watch с диагностикой |
| Документация | [CLI_PIPELINE_COMMANDS.md](CLI_PIPELINE_COMMANDS.md), ссылки из CLI/плагинной документации, примеры SSH и схемы стороннего модуля |

Дополнительно устранены обнаруженные проблемы существующего запуска:

- Реестр использовал Linux `/proc` и не распознавал Windows-пути. Проверка
  процессов и обнаружение теперь используют имеющуюся зависимость `psutil`,
  включая режим запуска с `--video`.
- `process.py --video` создавал конфиг, но передавал runtime исходный
  `args.config=None`. Runtime теперь получает сформированный путь.
- Схема fan-out предлагала неподдерживаемые значения. Используются фактические
  политики `forward_partial` и `drop_frame`.

Расширенный прогон: **327 тестов пройдены**. Дополнительно проверены **55
контрактов встроенных модулей**: источники, детекторы, трекеры, предобработка
и атрибуты. Для проверок кадров отдельно ожидается готовность spawn-worker;
холодный импорт библиотек не включается в таймаут обработки кадра.
Финальный повтор CLI после последних исправлений: **112 тестов пройдены**.
Проверки включают
unit/контрактные тесты, spawn-исполнение, чтение сохранённого
JSON snapshot через CLI, экранирование и скрытие секретов, валидацию, отмену,
резервные копии и их ротацию. В настоящем Windows PTY пройдены отказ от
сохранения с неизменённым файлом и подтверждение с записью и проверкой
содержимого резервной копии.

В этом проходе использовалось локальное Windows-окружение. Живые камеры,
нейросетевые модели и система на сервере не запускались. Отдельные workers
проверены на синтетических данных и сгенерированных видео; команды просмотра
и настройки — как операции над конфигами и опубликованной телеметрией.
Полноэкранный TUI, DAG и горячее подключение остаются согласованными
отложенными направлениями, а не незавершёнными пунктами этой версии.
